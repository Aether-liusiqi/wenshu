# 输出规范

> 本模块定义公文输出的格式标准。由 SKILL.md 在"输出规范"章节中引用。

## 一、格式要素（三大板块 18 要素）

### 版头（首页红色分隔线以上）
- 份号（6位阿拉伯数字，仅涉密公文）
- 密级和保密期限（"机密★5年"，3号黑体）
- 紧急程度（"特急"/"加急"，3号黑体）
- 发文机关标志（红色小标宋体，居中套红，上边缘距版心上边缘 35mm）
- 发文字号（机关代字 + 六角括号年份 + 流水号）
- 签发人（上行文必有，姓名用 3 号楷体）

### 主体（红色分隔线以下、末页首条分隔线以上）
- 标题（2 号小标宋体，红色分隔线下空二行居中）
- 主送机关（3号仿宋体，顶格）
- 正文（3 号仿宋体，每面 22 行 × 每行 28 字，固定行距 28 磅）
- 附件说明（正文下空一行，左空二字）
- 发文机关署名
- 成文日期（阿拉伯数字）
- 印章（骑年盖月，印章上沿不压正文）

### 版记（末页首条分隔线以下）
- 抄送机关（4 号仿宋体，左右各空一字）
- 印发机关和印发日期（4 号仿宋体）
- 页码（4 号半角宋体，单页右空一字双页左空一字，距版心下边缘 7mm）

**要素分层使用原则**：详见 `references/02-format-standards.md` 第〇章。从"必备"开始，逐层检查是否需要"常见"和"条件项"，"地方样式"除非用户明确要求否则不添加。

## 二、数字使用规范（GB/T 15835）

| 场景 | 使用 |
|------|------|
| 统计表中的数值 | 阿拉伯数字 |
| 公历世纪、年代、年、月、日、时刻 | 阿拉伯数字 |
| 法律法规条款编号 | 阿拉伯数字 |
| 定型的词（"十三五""星期五"） | 可用汉字 |
| 约数和概数（"三四十个""七八百元"） | 汉字数字 |

## 三、名称引用规范

- **人名**：引用全名，根据需要加注职务
- **地名**：使用标准地名，不用俗称或旧称
- **机关名**：全称或规范化简称（"国家发改委"是规范简称，"发改委"不是）
- **法律法规**：全称加书名号（《中华人民共和国劳动法》，不简写为"劳动法"）

## 四、文种速查表

> 详细内容见 `references/01-15-document-types.md` 和 `references/07-formal-materials.md`

### 法定公文 15 种

| 文种 | 行文方向 | 核心功能 | 典型场景 |
|------|---------|---------|---------|
| 决议 | 下行 | 会议通过的重大决策 | 党代会/全会通过的重要文件 |
| 决定 | 下行 | 对重要事项做出决策和部署 | 表彰、处分、政策性安排 |
| 命令(令) | 下行 | 颁布法规、人事任免、嘉奖惩戒 | 国务院令、主席令 |
| 公报 | 下行 | 公开发布重大事件或数据 | 人口普查公报、联合公报 |
| 公告 | 下行 | 向国内外宣布重要事项 | 重要人事变动、政策发布 |
| 通告 | 下行 | 在一定范围内公布应遵守事项 | 交通管制、行业规范 |
| 意见 | 多向 | 对重要问题提出见解和处理办法 | 指导意见、实施意见 |
| **通知** | 下行 | 发布、传达要求下级执行的事项 | 会议通知、工作部署 |
| **通报** | 下行 | 表彰先进、批评错误、传达精神 | 表彰通报、事故通报 |
| **报告** | 上行 | 向上级汇报工作、反映情况 | 年度总结、专题汇报 |
| **请示** | 上行 | 向上级请求指示、批准 | 经费请示、项目请示 |
| 批复 | 下行 | 答复下级请示事项 | 对请示的正式书面答复 |
| 议案 | 平行 | 政府向同级人大提交审议事项 | 法规议案、预算议案 |
| **函** | 平行 | 不相隶属机关间商洽、询问、答复 | 部门间协调、征求意见 |
| **纪要** | 多向 | 记载会议情况和议定事项 | 专题会议、常务会议 |

### 事务文书 7 种

| 文种 | 用途 | 典型场景 |
|------|------|---------|
| 工作总结 | 回顾阶段工作，梳理成绩与不足 | 年终总结、专项总结 |
| 工作方案 | 明确目标、任务、步骤、保障措施 | 实施方案、行动计划 |
| 讲话稿 | 领导在会议或活动中的发言文本 | 部署讲话、动员讲话 |
| 汇报材料 | 向上级或会议汇报工作进展 | 专题汇报、进度汇报 |
| 简报 | 简短快速反映工作动态 | 工作简报、信息简报 |
| 情况专报 | 针对特定事项的专门报告 | 舆情专报、事件专报 |
| 回复函 | 对来函/来件的正式书面答复 | 答复征求意见、答复询问 |

### 最易混淆的五对文种

1. **请示 vs 报告** — 请示求批准（上级必答），报告供知晓（上级不答）。请示事前行文，报告事后行文。
2. **公告 vs 通告** — 公告向"国内外"宣布；通告在"一定范围"内发布。县级教育局不能用公告。
3. **决定 vs 决议** — 决定可不经会议讨论；决议必须经会议表决通过。
4. **公报 vs 公告** — 公报内容详细、篇幅长；公告行文简约、篇幅短。
5. **通知 vs 通报** — 通知告知并要求执行；通报告知并教育比照。
