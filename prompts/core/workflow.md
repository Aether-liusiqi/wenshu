# 公文写作工作流

> 本模块定义 6 步写作流程。由 SKILL.md 在"写作流程"章节中引用。

## Step 1 — 场景识别

从用户输入中提取关键词，判断对应的公文场景，确定最合适的文种。

**法定公文路线**：
- 内部工作安排、要求下级执行 → 通知
- 向上级汇报工作、反映情况 → 报告
- 向上级请求指示、批准 → 请示
- 平级单位之间商洽、询问、答复 → 函
- 记载会议情况和议定事项 → 纪要
- 对重要事项做出决策、部署 → 决定
- 表彰先进、批评错误、传达精神 → 通报
- 向国内外宣布重要事项 → 公告
- 在一定范围内公布应遵守事项 → 通告
- 对重要问题提出见解和处理办法 → 意见
- 答复下级请示事项 → 批复

**事务文书路线**（无独立法律效力，但使用频率极高）：
- 回顾阶段工作、梳理成绩不足 → 工作总结
- 部署专项工作 → 工作方案
- 领导会议发言 → 讲话稿
- 向上级或会议汇报 → 汇报材料
- 简短快速反映动态 → 简报
- 针对特定事项专门报告 → 情况专报
- 答复征求意见/来函 → 回复函

**判断逻辑**：先看行文方向（上行/下行/平行），再看是否不相隶属（→函），再看是否求批准（→请示），最后看是否需会议表决（→决议 vs 决定）。

## Step 2 — 立意构思（三层穿透）

好的公文立意，在三个维度的交叉点上：

1. **向上穿透** — 理解上级精神和政策方向。这份公文要承接哪份上级文件的什么要求？
2. **向下穿透** — 掌握基层实情和执行瓶颈。这份公文要解决什么具体问题？
3. **向内穿透** — 评估本单位资源约束和能力边界。这个措辞我单位能否兑现？

三个层中任何一层缺失，公文就会变成"上面说的全对但做不了"或"下面提的都有理但不顾大局"或"本单位的计划很完美但既不接天线也不接地气"。

## Step 3 — 结构搭建（四种模式）

根据文种和内容选择最合适的结构：

- **总分式**：先总后分 — 先给出总体判断/总体要求，再逐项展开。适合通知、意见、报告。
- **并列式**：平铺直叙 — "一是……二是……三是……"。适合内容同等重要的部署。
- **递进式**：层层深入 — "是什么→为什么→怎么办" 或 "现状→问题→原因→对策"。适合调研报告、政策建议。
- **对比式**：新旧/正反/成绩与不足对比 — 适合需要强调变化的报告。

标题遵循基本公式：**发文机关 + 关于 + 事由 + 的 + 文种**。

## Step 4 — 正文撰写

**本步骤适用两类规则：**

### A. 文采增强（来自原文风）
- 语言通俗流畅，选择贴近生活的词语
- 运用排比句增强节奏感
- 可适度融入古诗词名句增强文采（在适当场景下）
- 重点选取关键精神意蕴的表述
- 结尾带出正面的价值观念

### B. 语言禁忌（高优先级 — 详细清单见 `references/08-language-taboos.md`）

以下三类词在公文中**严禁出现**：

**禁用主观评价词**：任何公文中不得使用"最好的""极大的""空前的""史无前例的""我们认为"等主观判断性词汇。用客观数据和事实陈述替代。

**禁用模糊时间词**：不得使用"尽快""抓紧""适时""择机""基本上"等没有时间边界、无法考核的模糊词。必须给出具体时限或量化标准。

**禁用绝对化用语**：不得使用"一定""必然""绝对""肯定""毫无疑问"等排除一切例外情况的绝对化判断。政策执行中总有特殊情况，公文的措辞必须为合法例外留出空间。

## Step 5 — 格式审查

写完后逐项核对：

- [ ] 发文字号的年份用六角括号〔〕
- [ ] 标题用 2 号小标宋体，正文用 3 号仿宋体
- [ ] 层次字体：一、(黑体) → (一)(楷体) → 1.(仿宋) → (1)(仿宋)
- [ ] 上行文有签发人（3 号楷体）
- [ ] 成文日期用阿拉伯数字
- [ ] 附件说明位置正确
- [ ] 版记抄送机关用 4 号仿宋体
- [ ] 页码左右各置一字线，距版心下边缘 7mm

也可运行 `python scripts/check_sections.py <文种> <文件.md>` 进行自动化校验。

## Step 6 — 输出交付

最终输出包含：

1. **完整公文正文**（可直接复制使用）
2. **文种说明**（为什么选这个文种 + 行文方向 + 注意事项）
3. **格式要点**（对排版人员的关键提示）
4. **替代方案**（如有多种写法可能，简要说明差异）
5. **语言自查**（对照 `references/08-language-taboos.md` 逐条确认无违规）
