# 约束与防护规则

> 本模块定义硬性约束和语言准则。由 SKILL.md 在"知识边界与约束"章节中引用。

## 一、硬性约束

1. **文种不可混淆。** 请示与报告严格区分 — 请示要求上级答复（事前行文，结尾"妥否，请批复"），报告不要求答复（事后行文，结尾"特此报告"）。标题中绝不能出现"请示报告"这一杂交名称。

2. **格式毫米级精确。** 发文字号中的年份必须用六角括号〔2024〕，绝不能用方括号 [] 或圆括号 ()。正文标题用 2 号小标宋体，正文用 3 号仿宋体，固定行距 28 磅。

3. **字体层级肌肉记忆。** 第一层"一、二、三"用黑体，第二层"（一）（二）（三）"用楷体，第三四层"1."和"（1）"用仿宋体。"黑一楷二仿三四"。

4. **不相隶属机关之间只用"函"。** 平级单位、无隶属关系的机关之间的公文往来一律用函，绝不能用通知或请示。

5. **一文一事。** 每份请示只写一个事项。每份通知聚焦一个主题。

6. **对于不在知识库中的信息，明确告知用户。不编造政策、不虚构数据、不过度美化。**

## 二、语言准则

### 准确优先

| 不准确的表达 | 准确的表达 |
|------------|-----------|
| "尽快完成" | "自收到本通知之日起 15 个工作日内完成" |
| "原则上同意" | "同意。请就以下细节进一步协商：……" |
| "有关部门" | 具体写出部门名称 |
| "适当调整" | "调整幅度不超过 10%" |

### 庄重

| 口语 | 庄重表达 |
|------|---------|
| "你们要好好干" | "请认真贯彻执行" |
| "我们觉得" | "经研究认为" |
| "这个事情" | "该事项" |
| "知道了" | "收悉" |

### 得体（区分高手的细微分水岭）

- 给上级："拟请审示"而不是"请批准"
- 给平级："拟请你单位协助"而不是"要求你单位配合"（没有隶属关系，无权"要求"）
- 给下级："请认真贯彻执行"（有隶属关系，可以使用指令性语言）

### 措辞力度精确

- "贯彻执行" ≠ "参照执行" ≠ "遵照执行"
- "贯彻执行" = 照做，有完整义务
- "遵照执行" = 照做，无需解读
- "参照执行" = 在对照精神范围内有自由度（"参照"是缓冲器——上级不确定条件是否普遍适用）

## 三、语言禁忌

> 详细清单见 `references/08-language-taboos.md`

**三大类红线**：
- 禁用主观评价词（"极大""空前""我们认为"）
- 禁用模糊时间词（"尽快""抓紧""适时""基本上"）
- 禁用绝对化用语（"一定""必然""绝对""毫无疑问"）

在 Step 4（正文撰写）和 Step 6（输出交付）之间，必须逐条对照 `references/08-language-taboos.md` 进行语言自查。
