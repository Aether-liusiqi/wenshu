# GB/T 9704-2012 格式标准速查

> 现行党政机关公文格式国家标准，2012年7月1日起与《条例》同步实施。

## 〇、要素分层体系

公文格式要素不是"越多越好"。本 Skill 采用五层分类法，根据文种和场景按需选用，避免无脑堆砌：

| 层级 | 含义 | 示例 | 处理方式 |
|------|------|------|---------|
| **必备** | 国标明确要求，不可省略 | 标题、正文、成文日期、印章 | 每份公文必须包含 |
| **常见** | 公开样例高频出现，默认保留 | 主送机关、附件说明、抄送机关 | 默认生成，可按需删减 |
| **条件项** | 仅在特定场景出现 | 份号（仅涉密件）、签发人（仅上行文）、紧急程度（仅急件） | 判断条件满足后才添加 |
| **地方或系统样式** | 各地/各单位自行约定 | 特定版头格式、信笺样式、内部编号体系 | 不主动添加，用户指定后才加 |
| **项目自定义** | Skill 为输出质量追加的口径 | 联系人附注（请示/报告/通知/函）、格式提示注释 | 标注为项目惯例，不冒充国标 |

**使用原则**：
- 从"必备"开始，逐层检查是否需要"常见"和"条件项"
- "地方样式"除非用户明确要求，否则不添加
- "项目自定义"内容在输出中用注释标明"（本 Skill 惯例，非国标要求）"

## 一、三大板块总览

```
┌─────────────────────────────────┐
│  版头（首页红色分隔线以上）       │
│  · 份号 / 密级 / 紧急程度        │
│  · 发文机关标志（红字）           │
│  · 发文字号 / 签发人              │
├─────────────────────────────────┤ ← 红色分隔线（与版心同宽）
│  主体                           │
│  · 标题（2号小标宋体）           │
│  · 主送机关                      │
│  · 正文（3号仿宋体）             │
│  · 附件说明 / 署名 / 日期 / 印章 │
├─────────────────────────────────┤ ← 黑色分隔线（与版心同宽）
│  版记                           │
│  · 抄送机关（4号仿宋体）         │
│  · 印发机关和印发日期             │
│  · 页码                          │
└─────────────────────────────────┘
```

## 二、版头要素

| 要素 | 层级 | 规范 | 关键细节 |
|------|------|------|---------|
| 份号 | 条件项 | 6位阿拉伯数字 | 仅涉密公文标注 |
| 密级和保密期限 | 条件项 | "机密★5年" | 顶格，3号黑体 |
| 紧急程度 | 条件项 | "特急"/"加急" | 顶格，3号黑体 |
| **发文机关标志** | **必备** | **红色小标宋体**，居中套红 | 上边缘距版心上边缘 **35mm** |
| 发文字号 | **必备** | 机关代字 + **〔年份〕** + 流水号 | ⚠️ 六角括号，禁用 [] 或 () |
| 签发人 | 条件项 | 姓名用 **3号楷体** | **仅上行文**有此要素 |
| 红色分隔线 | 常见 | 与版心同宽 | 隔开版头与主体 |

## 三、主体要素

| 要素 | 层级 | 规范 | 关键细节 |
|------|------|------|---------|
| **标题** | **必备** | **2号小标宋体**，居中 | 红色分隔线下 **空二行** 排布 |
| 主送机关 | 常见 | 3号仿宋体，顶格 | 多个主送用逗号分隔；纪要等文种可无 |
| **正文** | **必备** | **3号仿宋体** | 每面 **22行 × 每行28字**，固定行距 **28磅** |
| 附件说明 | 条件项 | 正文下空一行，左空二字 | 有附件时才标注 |
| 发文机关署名 | **必备** | 与正文末行保持适当距离 | — |
| **成文日期** | **必备** | **阿拉伯数字** | 如 "2026年6月5日"，不写"二〇二六年" |
| 印章 | **必备** | 骑年盖月 | 印章上沿不压正文 |
| 附注 | 条件项 | 成文日期下一行左空二字 | 请示需标注联系人；其他文种视需要 |

## 四、版记要素

| 要素 | 层级 | 规范 | 关键细节 |
|------|------|------|---------|
| 抄送机关 | 常见 | **4号仿宋体** | 左右各空一字；无抄送对象则不设版记 |
| 印发机关和日期 | 常见 | **4号仿宋体** | 印发日期用阿拉伯数字 |
| **页码** | **必备** | **4号半角宋体阿拉伯数字** | 左右各置一字线"－"，距版心下边缘 **7mm** |
| 页码位置 | **必备** | 单页右空一字，双页左空一字 | — |

## 五、正文层次结构

这是公文排版中最重要的"肌肉记忆"规则：

| 层次 | 标识 | 字体 |
|------|------|------|
| **第一层** | 一、二、三、…… | **黑体** |
| **第二层** | （一）（二）（三）…… | **楷体** |
| **第三层** | 1. 2. 3. …… | 仿宋体 |
| **第四层** | （1）（2）（3）…… | 仿宋体 |

> 记忆口诀："黑一楷二仿三四" — 到了第几层就换哪种字体。

## 六、核心参数速查

| 参数 | 标准值 |
|------|--------|
| 用纸 | A4（210mm × 297mm） |
| 版心尺寸 | 156mm × 225mm |
| 天头（上白边） | 37mm ± 1mm |
| 订口（左白边） | 28mm ± 1mm |
| 行距 | 固定值 28 磅 |
| 每面行数 | 22 行 |
| 每行字数 | 28 字 |
| 标题与红线间距 | 空二行 |
| 正文首行缩进 | 2 字符 |

## 七、高频格式错误

| 错误 | 正确做法 |
|------|---------|
| 发文字号用 [2024] 或 (2024) | 必须用〔2024〕（六角括号） |
| 年份简写为 24 | 必须写全 2024 |
| 第一层标题用楷体 | 第一层必须用**黑体** |
| 上行文缺签发人 | 上行文必须有签发人 |
| 成文日期用汉字 | 改用阿拉伯数字 |
| 正文行距为单倍行距 | 必须设为固定值 **28 磅** |
| 页码居中放置 | 单页右空一字 / 双页左空一字 |
| 序号前加"第"字 | "一、"不是"第一、" |
