# GB/T 9704-2012 格式标准速查

> 现行党政机关公文格式国家标准，2012年7月1日起与《条例》同步实施。

## 一、三大板块总览

```
┌─────────────────────────────────┐
│  版头（首页红色分隔线以上）       │
│  · 份号 / 密级 / 紧急程度        │
│  · 发文机关标志（红字）           │
│  · 发文字号 / 签发人              │
├─────────────────────────────────┤ ← 红色分隔线（与版心同宽）
│  主体                           │
│  · 标题（2号小标宋体）           │
│  · 主送机关                      │
│  · 正文（3号仿宋体）             │
│  · 附件说明 / 署名 / 日期 / 印章 │
├─────────────────────────────────┤ ← 黑色分隔线（与版心同宽）
│  版记                           │
│  · 抄送机关（4号仿宋体）         │
│  · 印发机关和印发日期             │
│  · 页码                          │
└─────────────────────────────────┘
```

## 二、版头要素

| 要素 | 规范 | 关键细节 |
|------|------|---------|
| 份号 | 6位阿拉伯数字 | 仅涉密公文标注 |
| 密级和保密期限 | "机密★5年" | 顶格，3号黑体 |
| 紧急程度 | "特急"/"加急" | 顶格，3号黑体 |
| **发文机关标志** | **红色小标宋体**，居中套红 | 上边缘距版心上边缘 **35mm** |
| 发文字号 | 机关代字 + **〔年份〕** + 流水号 | ⚠️ 六角括号，禁用 [] 或 () |
| 签发人 | 姓名用 **3号楷体** | **仅上行文**有此要素 |
| 红色分隔线 | 与版心同宽 | 隔开版头与主体 |

## 三、主体要素

| 要素 | 规范 | 关键细节 |
|------|------|---------|
| **标题** | **2号小标宋体**，居中 | 红色分隔线下 **空二行** 排布 |
| 主送机关 | 3号仿宋体，顶格 | 多个主送用逗号分隔 |
| **正文** | **3号仿宋体** | 每面 **22行 × 每行28字**，固定行距 **28磅** |
| 附件说明 | 正文下空一行，左空二字 | "附件：1. ×××" |
| 发文机关署名 | 与正文末行保持适当距离 | — |
| **成文日期** | **阿拉伯数字** | 如 "2026年6月5日"，不写"二〇二六年" |
| 印章 | 骑年盖月 | 印章上沿不压正文 |

## 四、版记要素

| 要素 | 规范 | 关键细节 |
|------|------|---------|
| 抄送机关 | **4号仿宋体** | 左右各空一字 |
| 印发机关和日期 | **4号仿宋体** | 印发日期用阿拉伯数字 |
| **页码** | **4号半角宋体阿拉伯数字** | 左右各置一字线"－"，距版心下边缘 **7mm** |
| 页码位置 | 单页右空一字，双页左空一字 | — |

## 五、正文层次结构

这是公文排版中最重要的"肌肉记忆"规则：

| 层次 | 标识 | 字体 |
|------|------|------|
| **第一层** | 一、二、三、…… | **黑体** |
| **第二层** | （一）（二）（三）…… | **楷体** |
| **第三层** | 1. 2. 3. …… | 仿宋体 |
| **第四层** | （1）（2）（3）…… | 仿宋体 |

> 记忆口诀："黑一楷二仿三四" — 到了第几层就换哪种字体。

## 六、核心参数速查

| 参数 | 标准值 |
|------|--------|
| 用纸 | A4（210mm × 297mm） |
| 版心尺寸 | 156mm × 225mm |
| 天头（上白边） | 37mm ± 1mm |
| 订口（左白边） | 28mm ± 1mm |
| 行距 | 固定值 28 磅 |
| 每面行数 | 22 行 |
| 每行字数 | 28 字 |
| 标题与红线间距 | 空二行 |
| 正文首行缩进 | 2 字符 |

## 七、高频格式错误

| 错误 | 正确做法 |
|------|---------|
| 发文字号用 [2024] 或 (2024) | 必须用〔2024〕（六角括号） |
| 年份简写为 24 | 必须写全 2024 |
| 第一层标题用楷体 | 第一层必须用**黑体** |
| 上行文缺签发人 | 上行文必须有签发人 |
| 成文日期用汉字 | 改用阿拉伯数字 |
| 正文行距为单倍行距 | 必须设为固定值 **28 磅** |
| 页码居中放置 | 单页右空一字 / 双页左空一字 |
| 序号前加"第"字 | "一、"不是"第一、" |
