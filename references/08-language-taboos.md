# 公文语言禁忌清单

> 第四步正文撰写的高优先级约束。写完正文后必须逐条自查。

## 一、禁用主观评价词

**规则**：公文中不得使用主观判断性词汇。所有评价必须基于客观事实和数据。

| 禁用 | 原因 | 替代方式 |
|------|------|---------|
| "取得了巨大成就" | "巨大"是未经定义的判断 | "地区生产总值增长 6.2%，高于全省 0.8 个百分点" |
| "得到了广泛好评" | "广泛""好评"无法量化 | "群众满意度达 95%" |
| "这是最好的方案" | "最好"是主观价值判断 | "该方案在三个备选方案中投资最少、工期最短" |
| "极大的推动了" | "极大"无法验证 | "推动……提升了 X 个百分点" |
| "空前的" | 历史比较缺乏依据 | "创近五年新高"（如有数据支撑） |
| "我们认为" | 公文以机关名义而非个人名义 | 直接陈述事实或"经研究认为" |
| "明显改善" | "明显"是主观感受 | "较上年提升 12 个百分点" |
| "深受欢迎" | 无法量化 | "参与率达 92%" |

## 二、禁用模糊时间词

**规则**：公文中不得使用没有时间边界的模糊词。每个时间承诺必须有具体的截止日期或量化标准。

| 禁用 | 问题 | 替代 |
|------|------|------|
| "尽快完成" | 没有时间边界，无法考核 | "自收到本通知之日起 15 个工作日内完成" |
| "抓紧落实" | 时间要求不具体 | "于 2026 年 3 月 31 日前落实到位" |
| "适时开展" | "适时"的决策主体和时间不明确 | "待条件成熟后"（仍需尽量给出触发条件） |
| "择机启动" | 同上 | "于 X 月底前启动" |
| "原则上" | 例外情况未界定 | "除以下情形外：……" 或直接去掉 |
| "基本上" | 模糊程度 | "完成率达 95% 以上" |
| "今后" | 时间范围无限 | "2026—2028 年" |
| "长期坚持" | 无法考核 | "持续推进，每年年底报告进展" |

## 三、禁用绝对化用语

**规则**：不得使用排除一切例外情况的绝对化判断。政策执行总有特殊情况，措辞必须为合法例外留出空间。

| 禁用 | 问题 | 替代 |
|------|------|------|
| "一定要" | 排除例外 | "应当"（法律用语，允许依法例外） |
| "必然" | 逻辑上可能被证伪 | "预计""预计将"（标注推断性质） |
| "绝对" | 不留弹性空间 | 直接删除或改为限定范围 |
| "毫无疑问" | 恰恰可能引发质疑 | 用事实代替断言 |
| "永远" | 没有时间边界 | "长期""持续" |
| "所有""全部" | 可能有例外 | "各级""各单位"（隐含范围但不绝对化） |
| "必须" | 对平级或上级不能用 | 上级对下级可用"必须"，平信用"拟请""商请"，对上级用"恳请" |

## 四、措辞力度错配

**规则**：措辞的力度必须与行文方向和发文主体权限匹配。

| 错配 | 问题 | 正确做法 |
|------|------|---------|
| 对平级用"要求" | 没有隶属关系，无权要求 | "拟请""商请""请予支持" |
| 对上级用"请批准" | 缺少尊重空间 | "拟请审示""恳请批复" |
| 对下级用"建议" | 有隶属关系却自降权威 | "请认真贯彻执行""请遵照执行" |
| "贯彻执行"混用"参照执行" | 法律和行政效力根本不同 | 前者=照做有完整义务；后者=有自由度 |
| 函中用"务必" | 平级无权"务必" | "盼请于 X 日前函复" |

## 五、事实与研判混淆

**规则**：事实描述和趋势研判必须在文本中明确分开。

| 错误做法 | 正确做法 |
|---------|---------|
| "该问题已严重影响社会稳定" | 事实："1 月发生相关信访 12 起"；研判："需关注事态进一步发展影响社会稳定的可能性" |
| "企业反响强烈" | 事实："收到企业反馈 45 件"；研判："反映出企业对政策调整关注度较高" |
| 研判不加依据标注 | "预计价格将回落" → "预计价格将回落（依据：去年同期在相似条件下价格 5 日内恢复正常；气象预报显示 6 月 5 日起天气转好）" |

## 六、自查流程

在 Step 5（格式审查）之前，执行以下自查：

1. 通读全文，用 Ctrl+F 搜索"尽快""抓紧""原则上""基本上""极大""空前""最好""一定""必然""绝对""毫无疑问""永远""所有""全部""我们认为"
2. 每找到一处，按上述清单替换或删除
3. 检查措辞力度与行文方向是否匹配：上行→尊敬但不卑微；下行→明确但不霸道；平行→商量但不软弱
4. 确认事实与研判在文本中有明确区分，研判均标注依据
