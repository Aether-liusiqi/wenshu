# 常见错误与避坑指南

公文写作的错误集中在三个层面：文种错误（逻辑错误）、格式错误（细节错误）、语言错误（判断错误）。

---

## 一、文种错误（最严重）

### 1. 请示报告中混用

| 错误表现 | 说明 |
|---------|------|
| 标题写"请示报告" | 公文体系中最致命的错误 — 等于宣称起草者不懂文种 |
| 用报告代替请示 | 上级不需要答复 — 你的申请不会被处理 |
| 在报告中夹带请示事项 | 违反"报告不得夹带请示事项"的规定 |

### 2. 不相隶属机关之间用错文种

| 错误表现 | 正确做法 |
|---------|---------|
| 平级单位发"通知" | 不相隶属机关之间一律用**函** |
| 向无隶属关系的机关发"请示" | 用函商洽 |
| 对平级单位用命令性语言 | 用"拟请""商请""敬请"等商量口吻 |

### 3. 公告/通告不分

| 错误 | 说明 |
|------|------|
| 县级教育局发布"公告" | 公告是向"国内外"宣布重要事项，县级单位无权使用 |
| 小区物业发"通告" | 通告是法定公文，只有国家机关可以使用 |

### 4. 决定/决议混淆

| 错误 | 正确做法 |
|------|---------|
| 把未经会议讨论的事项写成"决议" | 决议必须经会议表决通过 |
| 把会议表决通过的事项写成"决定" | 会议通过的用决议，领导机关直接做出的用决定 |

### 5. 通知/通报混用

通知的核心是"要求执行"，通报的核心是"教育比照"。部署工作的用通知，表彰/批评的用通报。

## 二、格式错误（高频考点）

### 发文字号

| 错误 | 正确 |
|------|------|
| [2024] 或 (2024) | **〔2024〕**（六角括号） |
| 24 | 必须写全 **2024** |

> 发文字号的六角括号是公文中"一眼错" — 有经验的考官在第一秒就会判定格式错误。

### 字体层级

| 错误 | 正确 |
|------|------|
| 第一层用楷体 | 第一层必须用**黑体** |
| 第二层用黑体 | 第二层必须用**楷体** |
| 所有层级用同一种字体 | 严格遵循"黑一楷二仿三四" |

### 其他格式错误

| 错误 | 正确 |
|------|------|
| 上行文缺签发人 | 上行文必须有签发人，姓名用 3 号楷体 |
| 成文日期用汉字 | 改用阿拉伯数字 |
| 正文行距为单倍行距 | 固定值 28 磅 |
| 标题距红线太近 | 红色分隔线下空二行 |
| 序号前加"第"字 | "一、"不是"第一、" |
| 页码居中 | 单页右空一字，双页左空一字 |
| 附件说明位置错误 | 正文下空一行，左空二字 |
| 印章压住正文 | 印章上沿不压正文（"骑年盖月"原则） |

## 三、语言错误

### 口语化

| 错误 | 正确 |
|------|------|
| "大家要重视" | "请各部门高度重视" |
| "知道了" | "收悉" |
| "这个事情很重要" | "该事项关系重大" |
| "好好干" | "认真贯彻执行" |

### 模糊表达

| 错误 | 问题 |
|------|------|
| "尽快" | 没有时间边界 → 无法考核 |
| "差不多" | 没有量化标准 |
| "原则上" | 例外情况未明确 |
| "各有关单位" | 谁是有关系？需具体列出 |

### 主观判断

| 错误 | 正确 |
|------|------|
| "我们认为这是最好的方案" | 给出方案的客观依据和比较分析 |
| "这明显是错误的" | "经核实，该做法与 XX 规定第 X 条不符" |
| "取得了巨大成就" | 用具体数据和事实说明 |

### 措辞暗示不当

| 错误 | 问题 |
|------|------|
| "建议尽快批复" | 请示中不能"建议"上级 — 改为"恳请批复" |
| "务必在周五前答复" | 函中不能"务必" — 改为"盼请于周五前函复" |
| "请遵照执行"（对平级） | 无权要求平级"遵照" — 改为"供参考"或"请研究" |

---

## 四、自查清单

写完后逐项核查：

### 文种层面
- [ ] 文种选择是否准确？有无"请示报告"等杂交名称？
- [ ] 行文方向是否正确？平级之间是否用了"通知"或"请示"？
- [ ] 请示是否一文一事？报告是否夹带了请示？
- [ ] 结尾语是否与文种匹配？

### 格式层面
- [ ] 发文字号的年份是六角括号吗？年份写全四位了吗？
- [ ] 标题、正文、签发人字体字号是否正确？
- [ ] 层次字体是否遵循"黑一楷二仿三四"？
- [ ] 成文日期是阿拉伯数字吗？
- [ ] 上行文有签发人吗？

### 语言层面
- [ ] 有无"尽快""抓紧""原则上"等模糊词？
- [ ] 有无口语化表达？
- [ ] 机关名称是全称或规范简称吗？
- [ ] 对上级/平级/下级的措辞得体吗？
