# 七种常见事务文书

> 事务文书不属于 15 种法定公文，但在实际工作场景中使用频率极高。它们没有国标格式强制要求，但形成了行业公认的写作惯例。

---

## 一、文种总览

| 文种 | 用途 | 行文方向 | 典型场景 |
|------|------|---------|---------|
| **工作总结** | 回顾阶段工作，总结成绩与不足 | 可上可下 | 年终总结、专项工作总结 |
| **工作方案** | 明确目标、任务、步骤、保障措施 | 可上可下 | 专项工作方案、实施方案 |
| **讲话稿** | 领导在会议或活动中的发言文本 | 多向 | 部署讲话、动员讲话、总结讲话 |
| **汇报材料** | 向上级或会议汇报工作进展 | 上行 | 专题汇报、进度汇报、调研汇报 |
| **简报** | 简短、快速地反映工作动态 | 多向 | 工作简报、信息简报、新闻简报 |
| **情况专报** | 针对特定事项的专门报告 | 上行 | 舆情专报、事件专报、信息专报 |
| **回复函**（事务） | 对来函/来件的正式书面答复 | 平行 | 答复征求意见、答复询问 |

---

## 二、与法定公文的区别

| 维度 | 法定公文 | 事务文书 |
|------|---------|---------|
| 法律效力 | 有法定效力 | 无独立法律效力 |
| 格式约束 | GB/T 9704-2012 严格规定 | 行业惯例，相对灵活 |
| 文种名称 | 15 种法定名称 | 无统一名称规范 |
| 发文主体 | 必须是法定机关 | 可为单位内设机构 |
| 印章要求 | 必须盖印章 | 视情况决定 |
| 归档管理 | 必须归档 | 重要的事务文书也需归档 |

## 三、各文种写作要点

### 工作总结

**核心结构**：总述 → 成绩 → 问题 → 打算

- 总述：一句话概括阶段工作主线
- 成绩：用数据说话，分类分条
- 问题：真实、具体、不回避
- 打算：务实、可操作

**要素分层**：
- 必备：标题、正文（成绩+问题+打算）、成文日期
- 常见：数据表格、分类小标题
- 条件项：附件（重要佐证材料）、对比数据（同比/环比）

### 工作方案

**核心结构**：总体要求 → 主要任务 → 实施步骤 → 保障措施

- 总体要求：目标是什么、达成什么标准
- 主要任务：分解为可执行的几个方面
- 实施步骤：时间节点 + 责任分工
- 保障措施：组织领导、经费保障、考核机制

**要素分层**：
- 必备：目标、任务、步骤、保障措施
- 常见：责任分工表、时间节点表
- 条件项：经费概算、风险评估

### 讲话稿

**核心结构**：开场 → 主体（3-4 个观点）→ 结尾

- 开场：点题 + 问候 + 明确场合
- 主体：每个观点 = 论点 + 论据 + 案例
- 结尾：总结号召或表态

**语言特点**：
- 口语化但庄重，适合朗读
- 节奏感强，多用排比和短句
- 适度融入个人风格

### 汇报材料

**核心结构**：背景 → 工作进展 → 主要做法 → 存在问题 → 下步打算

- 背景：为什么要做这项工作
- 工作进展：已完成、正在做、计划做
- 主要做法：可复制的经验
- 存在问题：实事求是，不回避
- 下步打算：具体的行动计划

### 简报

**核心结构**：导语 → 主体 → 结尾

- 导语：一段话概括全文（5W1H）
- 主体：详述最有价值的内容
- 篇幅：一般不超过 2000 字

**类型**：
- 工作简报：反映日常工作动态
- 信息简报：传递有价值的信息
- 新闻简报：面向公众的新闻式简报

### 情况专报

**核心结构**：事件概述 → 基本情况 → 趋势研判 → 工作建议

- 事件概述：发生了什么、时间地点影响
- 基本情况：事实层面的客观描述
- 趋势研判：基于事实的判断（标注研判依据）
- 工作建议：可操作的建议措施

**关键原则**：事实与研判严格分开。事实部分不掺杂判断，研判部分标注依据。

### 回复函（事务）

与法定公文"函"的区别：事务性回复函用于答复征求意见、询问等日常往来，格式相对灵活。但核心原则不变——不相隶属机关之间，语气商量而非命令。

**核心结构**：引用来函 → 逐条答复 → 总结

## 四、要素分层速查

| 文种 | 必备 | 常见 | 条件项 |
|------|------|------|--------|
| 工作总结 | 标题、正文、日期 | 数据表、小标题 | 附件、同比数据 |
| 工作方案 | 目标、任务、步骤、保障 | 责任表、时间表 | 经费概算、风险评估 |
| 讲话稿 | 开场、主体、结尾 | 案例、引用 | PPT 备注、互动设计 |
| 汇报材料 | 背景、进展、做法、建议 | 数据图表 | 附件、佐证材料 |
| 简报 | 导语、主体 | 图片（独立块）、来源 | 联系方式 |
| 情况专报 | 概述、基本情况、研判、建议 | 时间线、对比 | 附件、原始数据 |
| 回复函 | 引用来函、逐条答复 | — | 佐证材料 |
