# 公文写作核心方法论

## 一、立意：三层穿透法

好的公文立意，是在三个维度看似矛盾的要求之间找到交叉点：

```
        上级精神
        （政策方向、战略部署、文件精神）
           /\
          /  \
         /    \
        / 立意 \        ← 好的立意在这里
       /  交叉点 \
      /          \
     /____________\
下面实情            本地实际
（基层条件、        （本单位资源约束、
实际困难、          能力边界、
执行瓶颈）          优先事项）
```

### 穿透方法

1. **向上穿透** — 这份公文要承接哪份上级文件的什么要求？不看上级精神，公文就成了"在真空中写作"。
2. **向下穿透** — 基层的真实情况是什么？执行的最大瓶颈在哪里？不接地气，"上面说的全对但下面做不了"。
3. **向内穿透** — 本单位的资源能不能支撑这个承诺？这个措辞我单位能否兑现？没有自知之明，公文就成了空头支票。

> 三个层中任何一层缺失，公文就会变成"既不对上、也不对下、也不对自己负责"。

## 二、结构：四种基本模式

### 1. 总分式

先总后分 — 先给出总体判断/总体要求，再逐项展开。

**适用**：篇幅较长、内容复杂的通知、意见、报告。

```
总起：为贯彻落实……现将有关事项通知如下：
  一、……（分述要点一）
  二、……（分述要点二）
  三、……（分述要点三）
```

### 2. 并列式

几个平行的方面平铺直叙 — "一是……二是……三是……"。

**适用**：内容同等重要、逻辑并列的部署。

```
一、加强组织领导
二、健全工作机制
三、强化监督考核
四、营造良好氛围
```

### 3. 递进式

层层深入 — "是什么→为什么→怎么办"。

**适用**：需要完整论证的调研报告、政策建议。

```
一、基本情况（是什么 — 客观描述现状）
二、存在问题（为什么会这样 — 原因分析）
三、对策建议（怎么办 — 可操作的建议）
```

### 4. 对比式

新旧对比、正反对比、成绩与不足对比。

**适用**：需要强调变化或问题严重性的报告。

```
一、2025年工作回顾（成绩部分）
二、当前面临的困难与挑战（问题部分）
三、2026年工作思路（在新基础上规划）
```

## 三、标题提炼

### 基本公式

```
发文机关 + 关于 + 事由 + 的 + 文种
```

**示例**：
```
国务院 + 关于 + 进一步优化营商环境降低市场主体制度性交易成本 + 的 + 意见
```

### 标题的三秒判断

好标题让读者在三秒内精确判断：
- 这份文件在说什么事（事由）
- 它的效力有多大（文种 + 发文机关的级别）
- 我需不需要读（与我是否相关）

"关于进一步做好……工作的通知" — 传递的信号是日常行政维护
"关于全面深化……改革的若干意见" — 传递的信号是系统性变革

## 四、正文骨架搭建

### 引言（交代背景+目的）

```
为贯彻落实 XX 文件精神，进一步推动 XX 工作，
根据 XX 要求，结合我单位实际，现就 XX 事项通知如下：
```

### 主体（分段分条，逻辑清晰）

```
一、总体要求
二、主要任务
三、保障措施
四、工作要求
```

### 结尾（收束有力）

根据文种的不同选择相应的结尾策略：

- 部署性通知 — "以上通知，请认真贯彻执行"
- 报告 — "特此报告"
- 请示 — "妥否，请批复"
- 函 — "请函复" / "特此函复"

## 五、五个写作技巧

1. **一事一段，一段一意。** 每个自然段只说一个意思。段首句就是该段的核心观点。

2. **活用序号但不滥用。** 序号让结构清晰，但层级不宜超过四层。超过四层说明结构需要重构。

3. **关键位置放关键信息。** 每段的段首和段尾是最容易被注意到的位置 — 最重要的信息放在这里。

4. **数据说话，事实先行。** 用数据替代形容词。不说"取得了很大成绩"，说"增长率达到 8.5%"。不说"得到广泛好评"，说"群众满意度达 95%"。

5. **写完大声朗读一遍。** 朗读是发现语病的最快方法 — 读不顺的地方，写就一定有问题。
