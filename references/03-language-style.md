# 公文语言风格指南

## 一、四字准则

公文语言追求四个目标，排序本身就是一门艺术 — **准确性压倒一切**。

### 准确（第一准则）

公文不是文学作品。"大概""差不多""尽快""基本上" — 这些口头语在公文中等于没有说。

| 不准确的表达 | 准确的表达 |
|------------|-----------|
| "尽快完成" | "自收到本通知之日起 15 个工作日内完成" |
| "原则上同意" | "同意。请就以下细节进一步协商：……" |
| "有关部门" | 具体写出部门名称 |
| "适当调整" | "调整幅度不超过 10%" |

### 简洁

- "为了进一步推动和促进……" → 删掉"进一步"
- "在……的基础上" → 改成"基于……"
- 能用一句话的不拆成两段，能用一个词的不写成一句话

### 庄重

公文的庄重来自词的选择，不是句子的长度。

| 口语 | 庄重表达 |
|------|---------|
| "你们要好好干" | "请认真贯彻执行" |
| "我们觉得" | "经研究认为" |
| "这个事情" | "该事项" |
| "知道了" | "收悉" |

### 得体

"得体"是区分高手和新手的最细微分水岭。

- 给上级："拟请审示"而不是"请批准"（留出尊重空间）
- 给平级："拟请你单位协助"而不是"要求你单位配合"（没有隶属关系，无权"要求"）
- 给下级："请认真贯彻执行"（有隶属关系，可以使用指令性语言）

## 二、公文专用语库

### 开端语

| 用语 | 含义与使用场景 |
|------|--------------|
| 根据…… | 引用政策依据 |
| 按照…… | 引用操作规范 |
| 为了…… | 说明目的 |
| 关于…… | 引入事由 |
| 据悉…… | 引用已知信息 |
| 收悉 | 收到来文并已知悉（正式确认接收） |
| 阅悉 | 阅读并知悉 |
| 电悉 | 通过电传知悉 |

### 表态语（微妙程度递增）

| 用语 | 含义 |
|------|------|
| 同意 | 完全同意 |
| 原则同意 | 同意大方向，但细节需要协商 |
| 研究办理 | 当前不直接同意，但有可能 |
| 贯彻执行 | 照做，有完整义务 |
| 遵照执行 | 照做，无需解读 |
| 参照执行 | 在对照精神范围内有自由度 |

> ⚠️ "贯彻执行""遵照执行""参照执行"三个词在法律和行政效力上有根本不同，不可互换。"参照"是一个"缓冲器" — 上级不确定条件是否普遍适用，所以给出弹性空间。

### 结尾语

| 文种 | 标准结尾语 |
|------|-----------|
| 请示 | "妥否，请批复" / "以上请示如无不妥，请批复" |
| 报告 | "特此报告" |
| 批复 | "此复" |
| 通知 | "特此通知" |
| 函（询问） | "请函复" |
| 函（答复） | "特此函复" |
| 纪要 | 无固定结尾语 |

## 三、数字使用规范（GB/T 15835）

| 场景 | 使用 |
|------|------|
| 统计表中的数值 | 阿拉伯数字 |
| 公历世纪、年代、年、月、日、时刻 | 阿拉伯数字 |
| 法律法规条款编号 | 阿拉伯数字 |
| 文件发文字号中的数字 | 阿拉伯数字 |
| 定型的词（"十三五""星期五""五四运动"） | 可用汉字 |
| 约数和概数（"三四十个""七八百元""一百多人"） | 汉字数字 |
| 已定型的含阿拉伯数字的词语（"5G""3C"） | 保留阿拉伯数字 |

## 四、名称引用规范

### 人名
- 引用全名，根据需要加注职务
- 同一公文前后统一

### 地名
- 使用标准地名，不使用俗称或旧称
- "沪"是规范化简称，可以在发文字号等场景使用

### 机关名称
- **全称**：首次出现用全称
- **规范化简称**："国家发改委"是规范简称 ✓；"发改委"是不规范的口语简称 ✗
- 后文可统一用规范简称

### 法律法规
- 引用时使用全称加书名号
- 《中华人民共和国劳动法》— 正确
- "劳动法" — 不规范
- 《劳动法》— 在上下文已明确全称的前提下可使用

## 五、常见措辞陷阱

| 陷阱 | 说明 |
|------|------|
| "尽快""抓紧""基本上""原则上" | 模糊词 — 在公文中造成执行偏差 |
| "我们认为这是最好的方案" | 主观判断 — 改为基于事实的客观陈述 |
| 同名异指 | 全文中同一个简称不能指代两个不同的对象 |
| 过度修饰 | "极大的""巨大的""空前的" — 公文中慎用形容词最高级 |
| 隐含建议 | 在报告中夹带请示事项 — 违反"报告不得夹带请示"的规定 |
