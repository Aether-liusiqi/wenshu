# 范文：项目经费请示

**文种**：请示（上行文）
**适用场景**：向上级机关请求批准某一具体事项（经费、编制、项目等）
**格式要点**：一文一事；事前行文；结尾用"妥否，请批复"；上级必须答复

## 格式提示

1. 请示必须一文一事
2. 必须事前行文（不能做了再请示）
3. 结尾语"妥否，请批复"是请示的法定标识之一
4. 理由要充分：写了政策依据（上级文件）、资金测算（具体数据）、后果预警（资金可能被收回）
5. 金额要绝对准确，不能有"约""左右"等模糊词

## 写作要点注释

1. **请示的三段论结构。** 政策依据（第1段引用省厅通知）→ 资金测算（第2段用具体数字）→ 恳请事项（第3段明确金额）——这是请示的最优结构。三部分缺任何一块，上级都没有足够信息做决策。

2. **"如不能及时解决"的策略性。** 第2段的"如不能及时解决配套资金问题，将影响项目按期开工，可能导致上级资金被调整收回"——这不是威胁，而是据实告知决策后果。请示中陈述后果是可接受的，但不能用后果来"逼迫"上级。

3. **附件的作用。** 投资概算表不是可有可无的装饰——它是支撑"1050 万元"这个数字的唯一可信来源。没有概算表，"1050 万元"只是起草者的猜测。

4. **一文一事的严格执行。** 这份请示只申请了一件事（高标准农田建设配套资金）。如果同时申请"增加编制 2 名"——那就应该分成两份请示。一文多请会导致其中一件被搁置处理。

5. **"妥否，请批复"是请示的法定结尾。** 不能用"特此报告"（那是报告的结尾），也不能用"请审阅"（审阅不等于批复）。结尾语错了，文种就错了。
